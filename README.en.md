# 🌾 Farm Game
**[中文](README.md) | English**

A lightweight farming simulation game fully built with AI, featuring a UI based on Google Material 3.

**🎮 Play now** → [https://weilinfbk.github.io/farmgame/](https://weilinfbk.github.io/farmgame/)

---

## 📖 About the Game

Farm Game is an experiment in “zero hand-written code”: from the first line of code to the final visual presentation, the entire game was generated and iterated with AI assistance. It returns to the simplest core joy of farming games — planning your land, planting and tending crops, waiting for harvest, and enjoying the relaxed rhythm of each growth cycle.

The game is built with HTML5. Just open it in a browser — no installation or setup required.

## 🕹️ Core Gameplay

The gameplay is intentionally simple, with no complex stat stacking or forced quests:

- **Plant and harvest**: sow seeds, water your crops, and harvest them after they grow.
- **Resource loop**: sell your harvest for coins and use them to unlock new seeds or expand your farm.
- **Relaxed pace**: no timers or failure penalties — tend your farm at your own pace.

> *If the game also includes fishing, weather, building, or other mechanics, add them here.*

## 💾 Save System: Save Codes

The game supports saving and restoring progress through **save codes**, with no account or backend service required:

- **Export save**: generate a save code from your current progress and copy it for safekeeping.
- **Import save**: paste a save code to restore the corresponding game progress.
- **Cross-device friendly**: as long as you keep the save code, you can continue playing in another browser or on another device.

## 🎨 UI: Google Material 3

The interface is built with **Google Material 3 (M3)** design language:

- Uses M3 color system, rounded corners, elevation, and component styles
- Buttons, menus, status messages, and other interactive elements follow a consistent visual language
- Keeps the relaxed farming atmosphere while providing a clear, modern interface

## 🤖 Built with AI

This is not a project where AI merely helps with textures — it is a complete practice of **AI-led coding**.

### Development Approach: Vibe Coding

The project was developed in Vibe Coding mode: the human describes intent, judges the experience, and suggests changes, while AI turns natural-language requirements into runnable code. The project went through multiple iterations, gradually adding gameplay modules, the M3 interface, the save-code system, and interaction feedback.

### What AI Did

| Area | How AI Contributed |
|---|---|
| **Core logic** | Game mechanics such as the planting loop, growth stages, and economy system were generated by AI |
| **M3 interface** | Layouts, components, and visual styles based on Material 3 were implemented by AI |
| **Save system** | Save-code generation, copying, paste-import, and validation logic were completed by AI |
| **Interaction feedback** | Buttons, menus, status messages, and other interactions were implemented from descriptions |
| **Iteration** | Experience feedback was turned directly into prompts for AI to make corresponding changes |

### What This Means

Farm Game is also a sample of “what AI can build.” It does not aim for AAA-level complexity. Instead, it tests a simple question: **if someone has an idea but does not want to — or cannot — hand-write code, how far can AI take that idea?** The answer: at least far enough to produce a complete browser game with a full M3 interface and a save-code system.
